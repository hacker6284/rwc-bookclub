# Method

Source book: David Wong, *Real-World Cryptography* (purchased EPUB).

## Placement (redo)
English captions/transcripts are fetched for each in-scope video (YouTube captions when available; otherwise Whisper ASR from audio). A short content summary is written from the transcript. A video is attached to a Wong section (or Foundations) **only** when the transcript shows it actually teaches that topic. Title-substring heuristics are banned. Unplaced-in-scope is preferred over false friends (`digital`≠signatures, `hiding`≠commitments, Tor≠BitTorrent, breadboard≠Kerckhoff).

## Outline
Rebuilt from authoritative `chapter_headings.json`. No fabricated nodes (e.g. Tor is Wong §2.4.4; §12.3.1 is Volatility).
